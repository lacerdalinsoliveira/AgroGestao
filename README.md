**AgroGestão**



Sobre o projeto



O AgroGestão é um projeto de desenvolvimento de um aplicativo para auxiliar produtores rurais no gerenciamento de suas propriedades agrícolas.



&#x20;**Funcionalidades previstas**



\- Cadastro de propriedades rurais.

\- Controle de plantio e colheita.

\- Gerenciamento de estoque.

\- Consulta de informações e produtividade.



**Objetivo**



Facilitar a organização das atividades agrícolas por meio de uma solução digital simples e eficiente.
